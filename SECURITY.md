# Security

If you find a security problem in Loupe, please report it privately, not in a public issue. On GitHub, open the repository's **Security** tab and choose **Report a vulnerability**. Only the maintainer can see the report.

Please say what you found, how to reproduce it, and what it affects. You'll get a reply, and a fix if one is needed.

This is a personal project. There is no bug bounty.
