After 7b, files mode was also told to read files with Claude Code's Read tool, not shell commands such as cat, ls or find, since with the recommended permissions each of those asks the user. That line was added after 7b, and no run has confirmed it yet.

Two findings from the rerun shaped the setup guide:
- The first attempt at step A couldn't save the story. Claude Code ignores allow rules in a repository's `.claude/settings.json` until the folder is trusted, which a headless run never does. The rerun passed the same rules on the command line.
- There, `Edit(/loupe/**)` didn't match, but `Edit(loupe/**)` did. The guide now recommends `Edit(loupe/**)`, which Claude Code's docs say anchors at the same place in a project's settings.
