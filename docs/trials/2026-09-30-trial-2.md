# Trial 2: 2026-09-30

## Setup
Five Pellwick inputs, in three passes, each in its own Claude Project:
- **Pass A, baseline:** only the raw team files as project knowledge, skill off.
- **Pass B, setup:** Loupe set up the team from the raw files.
- **Pass C, Loupe:** only the files pass B produced, skill on.

Every run used the same prompt, "Write a user story with acceptance criteria for this. Use the attached team files.", and the same model, Sonnet 5.5 at Medium. One run each. The advisor who helped design Loupe ran the trial and scored it first. A separate reviewer then scored it blind.

The checker ran in claude.ai, on Node v22.22.2.

## Blind scores

| Measure | Loupe | Baseline |
|---|---|---|
| Right calls | 5 of 5 | 5 of 5 |
| Unsupported facts | 0 | 0 |
| Invented acceptance behavior | 3 | 3 |
| Usable estimates | 4 of 4 | 1 of 4 |
| Separates known, unknown and assumed, and rates confidence | Yes | No |
| Same format every time | Yes | No, it varies |
| Length | About 1.7 times the baseline | |
| Time per story | 1.5 to 2.5 minutes | 12 to 25 seconds |

## Where Loupe did better
- Usable estimates.
- It used the bug template for the bug.
- More build-blocking questions. For the address change it asked about the data model, validation and account security.

## Where the baseline did better
- Shorter.
- It used the team's change request form as written.
- It cited real documents.
- It wrote the definition of done as a checklist.

## Pass B, setup
- No facts from the raw files were dropped.
- It added four conclusions of its own to the context files, and they reached the stories.
- It turned the plain change request form into a checkable template, but copied placeholder values ("Medium", "2 to 4 hours") into it.

## Both missed
For the payment bug, whether subscribers already stuck with the banner clear on deploy or need a one-time fix.

## Why Loupe was slow
Each story run copied every context file and the template into its workspace ("Created 7 files" for one story), and one run re-checked the context files.

## Limits
- One run per input.
- A small, invented company.
- Review time was not measured.
