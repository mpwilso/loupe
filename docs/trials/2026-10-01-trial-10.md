# Trial 10: 2026-10-01

## Setup
- Story format v2, following [trial-10-plan.md](trial-10-plan.md): Loupe in Claude Code writing a story from each of five inputs, twice, each run in its own fresh copy made with `mktemp -d`, with the Pellwick team folder, the inputs in `notes/` and the skill installed per project. No tracker was loaded.
- Run headless with `claude -p`, on Sonnet 5.5 at Medium, in manual permission mode. The only allow rules were the ones in [claude-code.md](../claude-code.md), in each copy's untracked `.claude/settings.local.json`.
- The team folder's learned.md held three entries from trials 6 and 7, so some stories cite learned facts the v1 expected stories didn't have.
- It cost about $2.56.
- Results are from the saved outputs in `build/trial-10/`. Scenarios, unhappy paths and counts were taken by a script, `build/trial-10/analyze.py`. Every Known and Background fact, and every Example, was checked against its source by reading the input or context file it names. Measured by the Claude Code session that ran it, not blind.

## The bar, as set before the trial

- Every story passes the checker in the v2 shape.
- 0 Known or Background facts that their cited source doesn't say.
- 0 invented examples.
- Every scenario has an unhappy path (the checker enforces this).
- Compare against v1: count "To confirm" items and Unknowns per story, v1 against v2. Report it, don't gate on it.

The holiday cutoff email is a change request, which uses Pellwick's own team template with acceptance criteria, so it was judged on passing the checker in that template's shape.

## Trial 10c: unsettled behaviors, rerun
