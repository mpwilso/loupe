## Trackers
- Web app and product work: Jira, project "Subscriptions".
- Stockroom work: GitHub Issues in the stockroom repository, owned by the internal tools team.
- A story that changes both systems gets one Jira story and a linked GitHub issue.

## Words we use
- Subscriber: a customer with an active subscription.
- Box: one delivery of refills.
- Skip: leave out one box without cancelling.
- Cutoff: the last moment a box can change before the warehouse picks it. Today that is 72 hours before the ship date.

## Definition of done
Tested in staging, acceptance criteria checked by a tester, and support told about any change they will see.
