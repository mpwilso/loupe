## Trackers
- Web app and product work: Jira, project "Subscriptions". ("How we work" wiki page)
- Stockroom work: GitHub Issues in the stockroom repository, owned by the internal tools team. ("How we work" wiki page)
- A story that changes both systems gets one Jira story and a linked GitHub issue. ("How we work" wiki page)

## Words we use
- Subscriber: a customer with an active subscription. ("How we work" wiki page)
- Box: one delivery of refills. ("How we work" wiki page)
- Skip: leave out one box without cancelling. ("How we work" wiki page)
- Cutoff: the last moment a box can change before the warehouse picks it. Today that is 72 hours before the ship date. ("How we work" wiki page)

## Definition of done
- Tested in staging, acceptance criteria checked by a tester, and support told about any change they will see. (definition of done page)
