# How we work

Checked 2026-09-12. Priya Raman, product manager, added to it on 2026-09-11.

**Where tickets go.** Web app and product work lives in Jira, in the "Subscriptions" project. Stockroom work lives in GitHub Issues in the stockroom repository, which the internal tools team owns. If a story changes both, it gets one Jira story plus a linked GitHub issue.

**Words we use.**
Subscriber: a customer with an active subscription.
Box: one delivery of refills.
Skip: leaving out one box without cancelling.
Cutoff: the last moment a box can change before the warehouse picks it. Right now that's 72 hours before the ship date.
